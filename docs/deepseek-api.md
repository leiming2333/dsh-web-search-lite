# 接入 DeepSeek 官方搜索

这个插件装好就能搜——四家免密钥引擎（DuckDuckGo、Bing 网页、百度、360）开箱即用，不需要任何 key。

**接入官方搜索是可选项**，换来的是更稳的结果和更强的查询能力。下面是从零开始的完整步骤。

---

## 一、先想清楚：要不要配

| | 不配（免密钥） | 配官方 |
|---|---|---|
| 成本 | 0 元 | $0.75 / 千次搜索 |
| 要注册 | 不用 | DeepSeek 开放平台 + 充值 |
| 稳定性 | DDG 和 360 时不时失败 | 官方服务，不反爬 |
| 结果质量 | 四条抓取结果，排序参差 | 自研索引 + rerank + 权威度分级 |
| 查询语法 | 不支持 | `site:` / `lang:` / `after:` 等 |

**建议**：先用免密钥那几天，觉得够用就不必配；如果经常遇到“某家又挂了”或者想要更准的结果，再配。

---

## 二、获取 API Key

1. 打开 <https://platform.deepseek.com/api_keys>
2. 用 DeepSeek 账号登录（和网页版/App 是同一个账号）
3. 左侧点 **API keys** → **创建 API key**
4. 起个名字（比如 `dsh-search`），创建后**立刻复制**——弹窗关掉就看不到了

Key 形如 `sk-xxxxxxxxxxxxxxxx`。

### 充值

搜索按次计费，需要账户有余额：

1. 左侧点 **充值**
2. 新账号通常有**赠送额度**（控制台首页能看到余额）
3. 赠金用完再充值；扣费时**优先扣赠金**

**不充值也能试**：如果账户里有赠金，直接就能用。

---

## 三、填进插件

1. 打开 DSH → **设置 → 网络搜索**
2. **引擎**下拉选「**聚合模式**」
3. 找到「**DeepSeek 官方**」那一行，粘贴 key
4. 点「**保存**」
5. 点「**测试连接**」——会用已保存的配置真实搜一次，显示来源条数和耗时

服务地址已经预设好 `https://api.deepseek.com/v1/tools/search`，不用填。

**填完会发生什么**：聚合模式从“四家免密钥引擎”变成“四家 + 官方”，五个来源并发，结果合并去重。

---

## 四、它比别家多什么：查询语法

在搜索框里直接写，语法会原样传给官方引擎：

| 写法 | 作用 |
|---|---|
| `DeepSeek site:github.com` | 只搜这个站 |
| `DeepSeek site:github.com OR site:huggingface.co` | 搜多个站 |
| `DeepSeek -site:csdn.net` | 排除某站 |
| `DeepSeek "release notes"` | 精确短语 |
| `DeepSeek -广告` | 排除含该词的结果 |
| `DeepSeek lang:zh,en` | 限定语言 |
| `DeepSeek after:2026-01-01` | 限定发布时间 |
| `DeepSeek before:2026-06-01` | 限定之前 |

免密钥那四家是拼 URL 抓公开结果页，没有这层能力。

## 五、计费与限制

| 项目 | 数值 |
|---|---|
| 单价 | **$0.75 / 千次成功请求**（≈0.005 元/次） |
| 什么算一次 | 返回 HTTP 200 且结果非空 |
| **哪些不收费** | 空结果、失败、超时 |
| QPS | 100 |
| 结果数 | 每次 1–50 条（本插件按设置里的条数取） |

**算一笔账**：一天搜 20 次，一个月 ≈ 600 次 ≈ **3 元**。

---

## 六、一个容易踩的坑

DSH 里有两套官方搜索，计费方式不同：

| DSH 设置 | 搜索怎么执行 | 收费 |
|---|---|---|
| 网页搜索 = **DeepSeek (Legacy)** | 服务端工具，模型自己搜 | **不按次收费**，只算 token |
| 网页搜索 = **DeepSeek Search API** | 客户端直接调接口 | $0.75 / 千次 |
| **本插件** | 客户端直接调接口 | $0.75 / 千次 |

所以：

- **只是想让模型自己搜** → 用 Legacy，搜索本身不花钱
- **想在插件里做多源合并**（官方 + 四家抓取交叉对照）→ 才需要配这个 provider

两者不冲突，可以同时开。

---

## 七、常见错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `401` / 「API Key 无效」 | key 错、过期、或复制时带空格 | 重新复制，注意首尾 |
| `402` / 「余额不足」 | 赠金用完且没充值 | 充值 |
| `429` | 超过 100 QPS | 降低频率；个人使用基本碰不到 |
| `404` | 服务地址被改错了 | 清空地址栏，用预设值 |
| 测试连接失败但搜索能用 | 测试用的是已保存的配置 | 先点保存再测 |

---

## 八、为什么插件里没有别家 API

Tavily、Serper、Brave、Exa 这些第三方搜索 API 曾经支持过，后来移除了：

- **官方更便宜**：$0.75/千次，比多数第三方的基础档低
- **官方更稳**：不依赖第三方抓取的索引
- **官方支持查询语法**：第三方大多只有关键词匹配

如果你的场景确实需要别家的独立索引（比如 Brave 的隐私索引、Exa 的语义搜索），可以按 `index.js` 里 `searchDeepseek` 的写法加一个 `PROVIDERS` 条目 + 一个解析函数，去重、截断、渲染都是共享的，大概三十行。

---

## 九、密钥安全

- key 保存在 `~/.dsh/profiles/<profile>/storages/web-search-pro/settings.json`，**明文**
- 设置页只回传掩码（如 `sk-1…abcd`），完整 key 不会经过浏览器
- 别把这个文件提交到仓库或截图发出去
- 怀疑泄露：去 <https://platform.deepseek.com/api_keys> 删除旧 key、建新的
