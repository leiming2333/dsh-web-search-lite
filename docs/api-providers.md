# 搜索 API 配置指南

装好这个插件就能搜——四家免密钥引擎（DuckDuckGo、Bing 网页、百度、360）开箱即用。

配一家 API 是为了**稳定**：抓公开结果页这件事，引擎一改版就断，DDG 和 360 尤其明显。API 不会，而且返回带引用、有发布时间。

---

## 一分钟选型

| 你的情况 | 选这家 |
|---|---|
| 第一次配，想先试试 | **Tavily** — 每月 1000 次免费，注册最快 |
| 想要 Google 的排名 | **Serper** — 就是 Google 结果 |
| 想要独立索引（不依赖 Google/Bing） | **Brave** — 自建 300 亿页索引 |
| 做语义/相似内容搜索 | **Exa** — 按语义而非关键词匹配 |
| 只想要中文结果 | 不配也行，百度和 360 足够 |

> 额度与价格**以各家官网为准**——这类免费额度调整频繁，本文写的是 2026-11 的情况。

---

## Tavily

**适合**：第一次配、AI/RAG 场景。给的是"为一句话问题挑好的网页"，不是原始排名。

**注册**：<https://app.tavily.com/home>

1. 用邮箱或 Google 账号登录
2. 控制台首页就有 API Key，形如 `tvly-xxxxxxxx`
3. Free 计划每月 1000 credits，不需要绑卡

**填进插件**：设置 → 网络搜索 → 引擎选「聚合模式」→ 在 Tavily 那一行粘贴 key → 保存。

**注意**：Tavily 的 "credit" 和"一次搜索"不完全等价，`search_depth: basic` 消耗 1 credit，advanced 更多。免费额度够个人用到每天三十来次。

---

## Serper

**适合**：要 Google 结果（含 knowledge graph、related searches）。

**注册**：<https://serper.dev/api-key>

1. 邮箱注册，无需企业信息
2. 注册即送 2500 次查询（**一次性**，不是每月）
3. 控制台首页能复制 API Key

**填进插件**：同上，选 Serper 那一行。

**注意**：2500 次用完就要充值，最低 $50/5 万次。个人轻度使用能撑很久，重度用要算账。

---

## Brave Search

**适合**：想要一个不依赖 Google/Bing 的独立索引，隐私导向。

**注册**：<https://api.search.brave.com/app/keys>

1. 用邮箱注册开发者账号
2. 选 **Free** 计划：2000 次/月，1 次/秒
3. 创建 app 后拿 key

**填进插件**：同上。

**注意**：

- 注册时要选订阅方案，**必须勾选 "Data for AI"** 或 "Search" 用途，否则 key 调不通（会 403）
- Free 计划限制每秒 1 次请求，聚合模式下并发调用可能撞限流，这是正常的

---

## Exa

**适合**：语义搜索——"找和这段文字相似的页面"，而不是关键词匹配。

**注册**：<https://dashboard.exa.ai/api-keys>

1. 注册后送 $10 额度（按用量扣，不按次数）
2. Dashboard → API Keys → 创建

**填进插件**：同上。

**注意**：Exa 按 token 和搜索结果数计费，不是固定次数，$10 能用多久取决于查询复杂度。

---

## 怎么填（详细步骤）

1. 打开 DSH → **设置 → 网络搜索**
2. **引擎**下拉选「**聚合模式**」
   - 选它之后，下面会出现四家 API 的输入框
   - 想只测某一家，也可以直接选那家，就只有它一个输入框
3. 把 key 粘贴进对应那一行
4. 点「**保存**」
5. 点「**测试连接**」——会用已保存的配置真实跑一次查询，显示返回条数和耗时

**只填一家就够了**。没填 key 的那几家会被聚合模式自动跳过，不会报错拖累其他引擎。

## Bing Web Search API 为什么不在列表里

微软已于 **2025 年 8 月 11 日** 退役 Bing Search API v7：

- 所有端点返回 `410 Gone`
- 新注册在 2025 年 2 月就关闭了
- 官方替代品是 Azure AI Foundry 里的 "Grounding with Bing Search"，但那个返回的是**模型生成的答案**，不是可解析的结果列表，而且 $14/千次

所以这个插件里没有它——留着只会让人配了半天发现调不通。

如果你确实需要 Bing 的结果，走第三方 SERP 服务（SerpApi、DataForSeo 等），它们抓取 Bing 公开结果页转成 JSON。

## 和 DeepSeek 官方搜索的关系

DSH 内置了官方 Search API（`deepseek-search-api`），启用在 **插件 → 内置插件配置 → 网页搜索 → 启用新版 Web 搜索 API**。

两者的取舍：

| | 本插件的 API | DeepSeek 官方 |
|---|---|---|
| 成本 | 各家免费额度内为 0 | $0.75/千次（≈0.005 元/次）+ 模型 token |
| 配置 | 各家分别注册 | 一个 DeepSeek API key |
| 稳定性 | 依赖各家服务 | 官方服务 |
| 结果 | 可同时查多家并合并 | 单一来源 |

**如果你只是自己用 DSH**，官方那条更省事。这个插件的价值在"多源合并"（能看到哪家没收录）和"零成本兜底"（不配 key 也能搜）。

两者可以同时开——官方走它自己的通道，本插件走自己的四家，互不干扰。

## 常见错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `401 Unauthorized` | key 错误或已删除 | 回官网重新复制 |
| `402 Payment Required` | 余额/额度用完 | 充值，或等下个月额度重置 |
| `403 Forbidden` | key 权限不对（Brave 常见：没勾 "Data for AI"） | 重新创建 key 并选对用途 |
| `429 Too Many Requests` | 超限流（Brave Free 是 1 次/秒） | 降低搜索频率，或升级计划 |
| 结果里那家显示 `✗` | 该家这次失败，其他家照常返回 | 看工具输出里的错误原因，通常不影响整体 |
| 聚合模式只返回四家免密钥的结果 | 没填 key，或填了没保存 | 检查设置页该行是否显示"已配置密钥" |

## 关于密钥安全

- key 保存在 `~/.dsh/profiles/<profile>/storages/web-search-pro/settings.json`，是**明文**
- 设置页只回传掩码（如 `tvly…abcd`），完整 key 不会经过浏览器
- 别把这个文件提交到任何仓库，也别截图贴出来
- 每家都能在控制台**吊销并重建** key，怀疑泄露就换一个
